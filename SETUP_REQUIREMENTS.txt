2. GITHUB REPOSITORY SECRETS REQUIRED
--------------------------------------------------------------------------------
Navigate to: GitHub Repo -> Settings -> Secrets and variables -> Actions

Required Secrets:
  - SSH_HOST        : Server Public IP Address (e.g. 178.92.91.x)
  - SSH_USER        : Server SSH User (e.g. root)
  - SSH_KEY         : Private SSH Key (Full content of ~/.ssh/id_rsa or .pem file)
  - PORT            : 3001 (Avoids port 3000 collision with existing Grafana)
  - MONGO_URI       : mongodb://host.docker.internal:27018/sonar_db (or Mongo Atlas URI)
  - JWT_SECRET      : Your application JWT secret key
  - GEMINI_API_KEY  : Your Google Gemini API Key

5. SERVER NGINX & SSL (HTTPS) SETUP COMMANDS
--------------------------------------------------------------------------------
Run the following commands on your server (root@srv1789291):

# Step A: Create Nginx Reverse Proxy Config
cat << 'EOF' > /etc/nginx/sites-available/sonarapi.quotewear.store
server {
    listen 80;
    server_name sonarapi.quotewear.store;

    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

# Step B: Enable Site & Test Nginx Configuration
ln -sf /etc/nginx/sites-available/sonarapi.quotewear.store /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx

# Step C: Enable Free SSL Certificate (Certbot)
apt update && apt install -y certbot python3-certbot-nginx
certbot --nginx -d sonarapi.quotewear.store
